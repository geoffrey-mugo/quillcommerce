# Senior audit — 2026-09-16

Full-theme audit (engineer + merchant/customer lenses), building on the
same-day customer-journey review, dead-code sweep, and performance pass.

## Architecture assessment (preserved, not rewritten)

- **Component model is sound.** Every interactive feature is a
  self-registering custom element; all 18 components carry
  `disconnectedCallback` cleanup with `AbortController` signals — no
  leaked listeners, safe under Theme Editor section re-rendering, no
  double registration (`customElements.get` guards).
- **Coupling is minimal by design.** Cross-module communication happens
  only through two document-level events (`qc:cart-updated`,
  `qc:announce`) plus the `window.qcRoutes` locale-safe route map
  emitted by the layout. The 3-line `announce()` helper is duplicated
  per module deliberately — the event is the contract; a shared util
  would add an import dependency for no gain.
- **Scripts are scoped.** Layout loads only what every page needs
  (cart/count, quick view); sections load their own scripts
  (facets, product, slideshow, countdown, compare behind its setting,
  age gate behind its setting); drawer markup/JS render only when
  `cart_type` is `drawer`.
- **Progressive enhancement holds everywhere**: purchase, facets
  (URL-first with Apply fallback), quick view (plain link), drawer
  (cart page), menu (native details), gate (fails open).

## Issues found and fixed

1. **Drawer opener bound per-link** — a Theme Editor header re-render
   (or any late-rendered `[data-qc-cart-open]`) produced dead cart
   icons. Now a document-level delegated listener; also removes the
   drawer→header init-order coupling. Verified by self-replacing the
   header's innerHTML (killing all element listeners) and confirming
   the cart icon still opens the drawer.
2. **Age gate trapped merchants in the Theme Editor** — auto-open now
   skips `Shopify.designMode`.
3. **Slideshow ignored editor block selection** — selecting a slide
   block in the editor now shows that slide and holds autoplay until
   deselect (signal-scoped listeners).
4. **Fresh-store dead link** — preset/home templates pointed the hero's
   second CTA at `/pages/about-the-outfitter`, a 404 on any store but
   the demo; blanked in all four template copies (`/blogs/news` kept —
   it exists on every new store; `shopify://shop_images` refs resolve
   to nil on fresh stores and the hero degrades gracefully).

## Verified clean (no action)

- Race handling: in-flight `AbortController`s on quick view, facet
  swaps, cart line edits; busy flags on cart mutations; superseded
  quick-view responses discarded.
- No hardcoded store/domain assumptions in shipping files (provenance
  scan + URL grep); all Ajax goes through `routes.*` / `qcRoutes`.
- Image loading: 600px card crops with srcset, lazy defaults, eager
  LCP hero/first gallery slide.
- A11y baseline intact: Lighthouse 100 ×3, live region, dialog focus
  return, 44px targets, visible focus.
