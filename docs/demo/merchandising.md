# Homepage merchandising map

What each home section points at, so the home tells one coherent story with real
products. Section types are the existing SPEC-027 sections (revisited during the
theme unfreeze, per SPEC-029).

| Section | Content source | Notes |
|---|---|---|
| Hero (waterline) | Editorial image `river-hero` | Copy stays product-true: shells, layers, packs, rods. CTA 1 → `/collections/apparel`, CTA 2 → `/collections/equipment`. Replace the fictional "coordinates" eyebrow with a factual structural label (e.g. "Est. — river outfitter"). |
| Shop by condition | Conditions collections | 01 Cold water → `/collections/cold-water` · 02 Wet weather → `/collections/wet-weather` · 03 High sun → `/collections/high-sun` · 04 Base camp → `/collections/base-camp`. Tile images = each collection's featured shot. |
| Field kit (editorial + cards) | Collection `apparel` | Lead image `apparel-editorial`; cards = Storm Jacket, River Hoodie, Field Tee, Guide Cap (one coherent apparel set — never rods beside snowboards). |
| Material note | Image `material-closeup` | Statement about the 3-layer shell; three facts from Storm Jacket spec (face fabric, membrane, repair). |
| Field report | Article "Three cold mornings on the Deschutes" | Pull place/date/excerpt from field-reports.md Article 1; link → the article. |
| Service proof | Static (pages) | Repairs → `/pages/returns-repairs`, Returns, Shipping → `/pages/shipping`, Warranty. Factual, from pages.md. |

## Coherence rules
- The home shows **apparel** in the field-kit (coherent set), and **equipment**
  reaches through Conditions + nav — the two departments are both present without
  being mixed inside one grid.
- Every home image comes from the one editorial/product series (photography.md).
- No section links to an empty collection or an unpublished article.
